# Linux

Espaço para estudos de administração e segurança em ambientes Linux autorizados.

## Tópicos planejados

- sistema de arquivos e permissões;
- usuários, grupos e privilégios;
- processos, serviços e tarefas agendadas;
- logs do sistema;
- atualizações e configuração segura;
- comandos úteis para análise defensiva.
