# Estudos de Segurança da Informação

Repositório dedicado ao registro da minha evolução em **Segurança da Informação**, reunindo anotações próprias, laboratórios autorizados e pequenas automações.

O objetivo é documentar conceitos, práticas defensivas e aprendizados técnicos de forma organizada, ética e progressiva. Programação aparece como ferramenta complementar para compreender sistemas, analisar dados e automatizar tarefas.

## Trilhas de estudo

| Trilha | Conteúdo |
|---|---|
| [Fundamentos](fundamentos/) | Princípios de segurança, riscos, ameaças e controles |
| [Redes](redes/) | Protocolos, serviços, segmentação e análise de tráfego |
| [Linux](linux/) | Permissões, processos, logs e configuração segura |
| [Windows](windows/) | Contas, eventos, políticas e recursos de segurança |
| [Segurança Web](seguranca-web/) | HTTP, autenticação, sessões e vulnerabilidades comuns |
| [Criptografia](criptografia/) | Hashes, codificação, criptografia e assinaturas digitais |
| [Análise de Logs](analise-de-logs/) | Coleta, leitura, correlação e identificação de eventos |
| [Resposta a Incidentes](resposta-a-incidentes/) | Preparação, identificação, contenção e recuperação |
| [Automação com Python](automacao-python/) | Scripts defensivos e tratamento de dados de segurança |

## Como os estudos serão registrados

Cada anotação ou laboratório deve informar:

1. objetivo do estudo;
2. conceitos envolvidos;
3. ambiente utilizado;
4. procedimento executado;
5. resultado observado;
6. riscos e medidas de proteção;
7. referências consultadas;
8. aprendizados e próximos passos.

O arquivo [`MODELO-ANOTACAO.md`](MODELO-ANOTACAO.md) pode ser copiado para iniciar um novo registro.

## Uso ético

Todo conteúdo prático deve ser produzido em ambientes próprios, educacionais ou expressamente autorizados. Este repositório não deve conter:

- credenciais, tokens, chaves ou dados pessoais;
- informações que identifiquem alvos reais;
- respostas integrais ou flags de plataformas de treinamento;
- técnicas aplicadas a sistemas sem autorização;
- arquivos maliciosos ou dados obtidos de terceiros.

Consulte também [`ETICA-E-ESCOPO.md`](ETICA-E-ESCOPO.md).

## Aviso

Este é um repositório educacional em evolução. As anotações representam meu processo de aprendizado e não substituem documentação oficial, políticas organizacionais ou análise profissional especializada.
