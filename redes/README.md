# Redes

Espaço para compreender comunicações de rede e seus controles de segurança.

## Tópicos planejados

- modelos OSI e TCP/IP;
- endereçamento IP, portas e protocolos;
- DNS, DHCP, HTTP, HTTPS e SSH;
- segmentação, firewall e princípio do menor acesso;
- captura e análise de tráfego em laboratório;
- identificação de comportamentos anormais.
