# Segurança Web

Espaço para estudos realizados somente em aplicações próprias ou laboratórios autorizados.

## Tópicos planejados

- funcionamento de HTTP e HTTPS;
- autenticação, autorização e sessões;
- validação de entradas e saídas;
- gerenciamento seguro de credenciais;
- riscos comuns descritos pelo OWASP;
- cabeçalhos e configurações de segurança.
