# Automação com Python

Espaço para scripts pequenos, documentados e voltados a tarefas defensivas.

## Projetos planejados

- verificador de integridade de arquivos;
- analisador de logs fictícios;
- validador de força de senhas sem armazená-las;
- organizador de indicadores públicos;
- inventário de laboratório autorizado;
- geração de relatórios sanitizados.

Cada automação deverá incluir instruções de uso, limitações e cuidados de segurança.
