# Análise de Logs

Espaço para aprender a interpretar registros de sistemas e aplicações usando dados fictícios ou sanitizados.

## Tópicos planejados

- fontes e formatos de logs;
- eventos de autenticação e acesso;
- filtragem, normalização e correlação;
- indicadores de comportamento suspeito;
- criação de linhas do tempo;
- documentação de evidências sem dados sensíveis.
