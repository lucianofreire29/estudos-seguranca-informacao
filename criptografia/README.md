# Criptografia

Espaço para diferenciar e aplicar corretamente conceitos criptográficos básicos.

## Tópicos planejados

- codificação, hash e criptografia;
- criptografia simétrica e assimétrica;
- integridade de arquivos com hashes;
- assinaturas e certificados digitais;
- armazenamento seguro de senhas;
- limitações e escolhas de algoritmos.
